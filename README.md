# Battleship

A browser-based version of the classic Battleship game, built as the final project for The Odin Project's JavaScript course.

> 🚧 **Work in progress.** This project is still being built — some features may be incomplete, missing, or broken. Come back soon for the finished version!

## About

This project focuses on:
- Test-driven development (TDD)
- Separating game logic from the DOM
- Object-oriented / factory-based JavaScript
- Webpack for bundling

## Tech Stack

- Vanilla JavaScript
- HTML & CSS
- Vitest (testing)
- Vite (build tool)

## Skills Demonstrated

This project was built to practise and demonstrate:

- **Test-driven development** — writing tests before implementation using Vitest
- **Separation of concerns** — decoupling game logic from DOM manipulation for maintainable, testable code
- **Object-oriented / factory function design** — modelling game entities (players, ships, gameboards) as reusable, composable objects
- **Modular JavaScript architecture** — organising code across ES modules rather than a single script
- **Modern tooling** — using Vite for fast local development and optimised builds
- **Problem decomposition** — breaking a complex game (turn logic, hit detection, win conditions) into small, testable units
